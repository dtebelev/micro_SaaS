# Тех-план — Autism Content Engine (рабочее имя: NaturoPin)

## Профиль
- **Трек:** 📱 веб-приложение (PWA)
- **Гео:** 🌍 деплой на Vercel; интерфейс и карточки **на русском** (первый тест — Россия, потом выход на мир)
- **Архетип:** Генератор («статья → пакет пинов»)
- **Пользователь:** Наташа — эксперт по аутизму, «мама-оркестр» в дефиците времени. Голос: методист, бережно, без «AI-восторгов».

---

## Один живой путь (труба Этапа 1)

**ВХОД:** Наташа входит (простой email-вход) → вставляет **ссылку на статью ИЛИ её текст** в поле → жмёт «Выделить смыслы». Если это ссылка — сервер сам читает статью (Jina Reader, без ключа; фолбэк — прямой fetch).

**ОБРАБОТКА (гибрид: войлочный фон от FLUX + текст кодом):** формат — **story-пин**.
1. **Методист (LLM через OpenRouter)** читает блог-пост → пак пинов; по каждому: `title` (SEO-заголовок, правила в `spec/ПРОМПТ-1-ЗАГОЛОВОК.md`), `hook` (тёплый рассказ-крючок), `scene` (англ. описание войлочной сцены), `description`, `hashtags`.
2. **FLUX-2 / flash (fal.ai)** рисует **войлочную 3D-сцену БЕЗ текста** (приглушённые зелёные, стиль NATURONATA).
3. **Satori-рендер (код)** кладёт вторым слоем: логотип, заголовок (Playfair), рассказ-хук (Inter), объёмную кнопку «Сохранить, чтобы не потерять», `@naturonata`. Кириллица всегда 100% верная.
4. **Сохранение:** проект + пины в БД Supabase, PNG (фон и финальная карточка) — в Storage.

> Почему гибрид: тест показал, что FLUX отлично держит стиль, но путает кириллицу (ошибки, призрачные дубли). Текст кодом = гарантия правильных букв, дешевле и быстрее. Детали — в `spec/FLUX-ПРОМПТ.md`.
- **Авторизация:** простой вход, одна роль. Пользователь видит только свои проекты (RLS «вижу только своё»). Ключи нейросетей — **на сервере, платит владелец** (пользователь свой ключ не вводит).

**ВЫХОД:** экран **«Верстак»** — сетка карточек. На каждой: **«Перегенерировать»** (можно дописать короткую правку → FLUX рисует заново) и **«Скрыть»**. Кнопка «Подготовить архив» → **ZIP**: папка `/pins` с PNG + `pinterest_metadata.txt` (заголовок, описание, хэштеги по каждому пину) → скачать.

Одним предложением:
> **ВХОД** (вставил текст статьи) → **ОБРАБОТКА** (LLM разложила на смыслы → FLUX нарисовал фон → Satori наложил текст/рамку → сохранили) → **ВЫХОД** (сетка карточек → правки/скрытие → скачал ZIP для Pinterest).

## Данные (таблицы Supabase)

- **`profiles`** — пользователь (связка с Supabase Auth): `id`, `email`, `created_at`.
- **`projects`** — один прогон = одна статья: `id`, `user_id`, `source_text` (вставленный текст), `title`, `status` (`processing` / `ready` / `error`), `created_at`.
- **`pins`** — story-пины проекта: `id`, `project_id`, `title` (SEO-заголовок), `hook` (рассказ-крючок), `scene` (описание войлочной сцены для FLUX), `description`, `hashtags`, `image_path`, `image_prompt`, `position`, `status` (`ok` / `нужна_правка` / `скрыт`), `created_at`. *(Старые поля `type/items/icon_keys/cta/hero_object/motif` больше не используются.)*
- **Storage bucket `pins`** — PNG-карточки (приватный, доступ по подписанным ссылкам).

## Вход (авторизация)
**Простой** — email (magic-link через Supabase Auth). Одна роль. RLS: пользователь читает/пишет только свои `projects` и `pins`.

## Светофор
- 🟢 вход-текст · сохранение в БД · экспорт ZIP с `pinterest_metadata.txt` · простой вход · **текст на карточке (Satori — кириллица всегда верная)**
- 🟡 генерация фона FLUX-2/flash · сборка карточки Satori (фон+текст+иконки+рамка) · «Верстак» с перегенерацией/скрытием
- 🔴 **ядро** — красивая карточка в стиле NATURONATA из статьи (стиль решён гибридом: FLUX-фон + текст кодом; риск кириллицы снят).
  **В Ч1 — тонкий, но настоящий срез:** одна статья → **настоящая генерация ~6 карточек** и рабочий экспорт. (Число карточек — параметр в конфиге, легко поднять.)

## План Этапа 1 (шаги)

1. **Каркас приложения** — Vite + React + Tailwind; подтянуть палитру/шрифты из `design/Design.md` (Playfair Display + Inter, фон `#fafcd5`, скругления 48px). Экраны из прототипа: Вход → Анализ → Верстак → Финиш.
2. **Supabase** — таблицы `profiles`, `projects`, `pins`; bucket `pins`; включить Auth (magic-link) и RLS «вижу только своё».
3. **Экран Входа** — поле для текста статьи + кнопка «Выделить смыслы» + состояния ошибок (пусто/сбой). Тексты — из `content/экраны-тексты.md`.
4. **Edge Function `generate`** (клей на сервере):
   - шаг 1: вызов LLM (OpenRouter) → JSON по каждой карточке (тип, заголовок, пункты, icon_keys, cta, hero_object, motif, description, hashtags);
   - шаг 2: вызов FLUX-2/flash → фон-иллюстрация (без текста) в Storage;
   - шаг 3: Satori-рендер (фон + текст + иконки + рамка/лого, шрифты Playfair+Inter) → финальная карточка PNG в Storage;
   - запись `projects` + `pins`.
5. **Набор иконок и рамка** — лаконичные SVG-иконки (по `icon_keys`) + PNG-логотип NATURONATA и плашка-прогресс для оверлея.
6. **Экран Анализа** — прогресс со статусами («Ищем чек-листы…», «Упаковываем советы…», «Собираем карточки…»).
7. **Экран Верстак** — сетка карточек; кнопки «Перегенерировать» (с полем короткой правки) и «Скрыть».
8. **Экспорт** — сборка ZIP (`/pins/*.png` + `pinterest_metadata.txt`) на клиенте (JSZip) и скачивание; экран Финиш.
9. **Деплой на Vercel**, PWA-манифест; проверка сквозного пути на настоящей статье Наташи.

## Определение готовности (чек-лист Этапа 1)
Готово, когда:
- [ ] пользователь вошёл и вставил настоящий текст статьи;
- [ ] труба прошла целиком: LLM → FLUX-фон → Satori-текст/рамка → сохранение;
- [ ] русский текст на карточках чистый (без ошибок и дублей);
- [ ] на «Верстаке» видна сетка **настоящих** сгенерированных карточек (~6), работают «Перегенерировать» и «Скрыть»;
- [ ] скачивается ZIP с PNG и `pinterest_metadata.txt`;
- [ ] приложение открывается по ссылке (Vercel) на русском.
