# Настройка — что подключить и какой ключ

> Всё ставит и подключает **агент по промпту**. Ты только регистрируешься там, куда я укажу, и приносишь ключ. Регистрации — **по ходу стройки** (когда дойдём до сервиса), не всё сразу.
> **Ключи никогда не идут во фронтенд и не пишутся в открытый чат.** Публичные — в `.env`; секретные — в Supabase Edge Functions / переменные Vercel.

---

## Базовое (нужно всем)

| Сервис | Что берём | Где взять |
| :--- | :--- | :--- |
| **GitHub** | репозиторий для кода и деплоя | github.com → New repository |
| **Supabase** | база + вход + хранилище файлов | supabase.com → New project → Settings → API: `Project URL`, `anon key` (публичные, в `.env`), `service_role key` (**секретный**, только на сервере) |
| **Vercel** | хостинг сайта (весь мир) | vercel.com → Import из GitHub; переменные окружения задаём в проекте Vercel |
| **Stitch (уже есть)** | экраны/дизайн → React | прототип и `design/Design.md` уже в проекте |

## Под этот продукт

| Что | Зачем | Ключ / где взять | Куда кладём |
| :--- | :--- | :--- | :--- |
| **OpenRouter** | текстовая нейросеть-«методист» (разбор статьи → JSON карточек) | openrouter.ai → Keys | секрет → Edge Function |
| **FLUX-2 / flash (fal.ai)** | рисует **фон-иллюстрацию без текста** | fal.ai → Dashboard → API Keys (`FLUX_API_KEY`, провайдер `fal`) | секрет → Edge Function |
| **Satori-рендер (код, без ключа)** | накладывает русский текст + иконки + рамку/лого поверх фона | библиотека в проекте (`satori` + `@resvg/resvg-js` или `@vercel/og`) + шрифты Playfair Display, Inter (`.ttf` в репо) | код на сервере |
| **Логотип + иконки** | PNG-логотип NATURONATA, плашка-прогресс, набор SVG-иконок | файлы в проекте (`assets/`) | — |

## Ключи — куда именно
- **Публичные** (`Supabase URL`, `anon key`) → `.env` фронтенда и переменные Vercel.
- **Секретные** (`service_role`, `OpenRouter`, `FLUX/fal/Replicate`) → **только** секреты Supabase Edge Functions. Во фронт не попадают никогда.

## Чтение статьи по ссылке — ✅ подключено (без ключа)
- **Jina Reader** (`https://r.jina.ai/<url>`) — читает статью по URL, **ключ не нужен**. Фолбэк — прямой fetch+очистка. Модуль `server/pipeline/fetchArticle.js`.
