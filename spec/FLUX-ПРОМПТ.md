# Story-пин NaturoPin = войлочный фон (FLUX) + текст кодом (Satori)

Формат карточки (эталон «Выгорание у родителей детей с РАС…»):
**ЗАГОЛОВОК** (SEO, из первой ИИ) + короткий **РАССКАЗ-хук** + большая **войлочная 3D-сцена** +
объёмная кнопка **«Сохранить, чтобы не потерять»** + **@naturonata** + **логотип** сверху-слева.

Гибрид: FLUX рисует только войлочную сцену **без текста**; заголовок/хук/кнопку/хендл/лого
кладём **вторым слоем кодом** (Satori, шрифты Playfair Display + Inter) — кириллица всегда верная.

## Первая ИИ (методист)
Читает блог-пост → пак пинов. По каждому: `title` (правила — `spec/ПРОМПТ-1-ЗАГОЛОВОК.md`),
`hook` (1–2 тёплые фразы), `scene` (англ. описание войлочной сцены), `description`, `hashtags`.
Реализация: `server/pipeline/llm.js`.

## FLUX-промпт (войлочная сцена, без текста) — `server/pipeline/flux.js`
Ключевые черты стиля:
- **needle-felted wool 3D diorama**, handmade storybook craft, пушистая матовая шерстяная текстура;
- палитра: приглушённые sage/olive/forest-green на тёплом кремовом (#f6f8dc), один золотисто-лаймовый акцент;
- **жёстко:** каждый объект в этой палитре, БЕЗ насыщенного красного/ярких цветов;
- сцена в нижних 2/3, верхняя треть — чистая под текст;
- вертикаль 2:3 (1024×1536); тёплый, нежный, обнадёживающий тон;
- **ABSOLUTELY NO TEXT / LETTERS / WORDS / NUMBERS / LOGOS / WATERMARKS** — чисто иллюстрация.

Слот: `scene` (из методиста). fal.ai `fal-ai/flux-2/flash`, `image_size {width:1024,height:1536}`.

## Слой текста (Satori) — `server/pipeline/render.js`
- **логотип** NATURONATA — PNG из `assets/brand/logo.png` (если нет — словесный fallback);
- **заголовок** — Playfair Display 700, тёмно-зелёный (#0e401c), 2–4 строки, авторазмер;
- **рассказ-хук** — Inter, приглушённая олива;
- **войлочный фон** виден в середине/низу (кремовая вуаль плотная только вверху — прячет возможный вотермарк FLUX);
- **3D-кнопка** «Сохранить, чтобы не потерять» — оливковый градиент + объёмная тень, белый текст;
- **@naturonata** — на мягкой кремовой плашке снизу-слева.

## Труба одного пина
методист (JSON) → FLUX (войлочный фон) → Satori (заголовок+хук+кнопка+хендл+лого) → PNG → Storage + БД
(`pins.hook`, `pins.scene` — новые колонки).

## Проверено
`npm run test:storypin` — реальная генерация: войлочная сцена + чистый русский заголовок/хук + кнопка + хендл.
Результат в `output/flux-tests/`.
