# Предварительное ТЗ: Autism Content Engine (MVP)

**Продукт:** AI-система для автоматического превращения экспертных материалов по аутизму в образовательный Pinterest-контент.

---

## 🚦 Светофор реализуемости (Feasibility Matrix)

| Фича | Связка / Технология | Статус | Комментарий |
| :--- | :--- | :---: | :--- |
| **Input: URL + Text** | Firecrawl / Jina AI + LangChain | 🟢 | Зрелые инструменты для парсинга и очистки контента. |
| **AI Pin Pack Selection** | LLM (Claude 3.5 Sonnet / GPT-4o) | 🟢 | Отлично справляется с суммаризацией и классификацией по ролям. |
| **Visual Formats Generation** | Canvas API / Satori / Remotion (статично) | 🟡 | Сложнее всего — обеспечить "сенсорную чистоту" и качественную верстку текста AI. |
| **Full Mini-Editor** | React/Next.js State + Re-render | 🟡 | Требует качественного UI для правки текста и замены иконок без Canva-сложности. |
| **Zip Export (PNG + Text)** | JSZip + Metadata file | 🟢 | Стандартная задача, легко реализуема в Web App. |

---

## 1. Сбор контента (Input Phase)
*   **Механика:** Единое поле ввода, принимающее либо ссылку, либо вставленный текст.
*   **Логика:** Система очищает вход от скриптов/меню/рекламы (если URL) и передает LLM только "мясо" статьи.

## 2. Смысловое ядро (AI Analysis)
*   **Автоматический подбор:** AI анализирует объем и структуру текста, выбирая оптимальные 8–15 форматов:
    *   *Чек-лист* (подготовка к школе, сенсорный набор).
    *   *Памятка* (что делать при мелтдауне).
    *   *Пошаговый алгоритм* (визуальное расписание).
    *   *Карточка советов* (для родителей "Марин").
*   **Голос бренда:** Сохранение тональности эксперта (эмпиризм, поддержка, доказательность).

## 3. Визуальный движок (Autism Visual Guide)
*   **Стиль:** Сенсорно-спокойный. Отсутствие "кричащих" цветов, высокая читаемость, четкая иерархия.
*   **Библиотека иконок:** Использование лаконичных образовательных пиктограмм (не фотореалистичный AI-треш).

## 4. Проверка и Редактирование (Quick Approval)
*   **Интерфейс:** Веер карточек (пинов).
*   **Инструменты правки:**
    *   Клик по тексту на карточке открывает поле ввода для быстрой коррекции.
    *   Кнопка "Заменить иконку" (выбор из 3-4 альтернатив от AI).
    *   Кнопка "Регенерировать визуал" (если композиция не удалась).

## 5. Выдача (Export)
*   **Результат:** Один ZIP-файл.
*   **Состав:**
    *   Папка `/pins` с PNG картинками.
    *   Файл `pinterest_metadata.txt` — содержит названия (Title), описания (Description) и предложенные хештеги для каждого пина.
