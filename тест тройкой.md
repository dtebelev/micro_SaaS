# Тест тройкой: Autism Content Engine (MVP)

Этот документ предназначен для проведения тестирования продукта с реальными пользователями (в "тройках") и сбора обратной связи через формы.

---

## 🛠 ТЕСТ-ПРОТОТИП НА ТРОЙКИ (Framework)

**Состав команды тестирования:**
1. **Модератор:** Ведет пользователя по сценарию, не подсказывает.
2. **Пользователь (Наташа):** Эксперт, который пробует продукт.
3. **Наблюдатель:** Записывает эмоции, затыки и фразы пользователя.

**Легенда для пользователя:**
"Наташа, ты эксперт с плотным графиком. У тебя есть важная статья, но нет времени на дизайн. Мы создали инструмент, который 'понимает' твою экспертизу и упаковывает её в образовательные форматы для Pinterest. Попробуй превратить свою статью в готовый пак".

---

## 🎯 ФОКУС-ВНИМАНИЕ. БЛОК 1: ЗАДАЧА ДЛЯ ЖИВОЙ ТРОЙКИ

**Цель:** Проверить "Точку Ага" — момент, когда пользователь видит готовый визуал и понимает, что Canva больше не нужна.

**Задания для пользователя:**
1. **Вход:** Вставь ссылку на свою статью в поле ввода. Что ты ожидаешь увидеть после нажатия кнопки?
2. **Анализ:** Пока идет процесс, прочитай статусы ("Методист анализирует...", "Проверка сенсорной чистоты"). Вызывают ли они доверие?
3. **Верстак:** Перед тобой 12 карточек. Найди ту, которая лучше всего отражает твою мысль. 
4. **Редактирование:** Попробуй изменить одно слово в заголовке прямо на карточке. Удобно?
5. **Финиш:** Скачай архив. Оцени состав файла `pinterest_metadata.txt`.

**На что смотреть наблюдателю:**
- *Вздох облегчения* при появлении сетки карточек (успех визуальной системы).
- *Недоумение* на этапе анализа (проблема с копирайтингом или скоростью).
- *Желание всё переделать* (сигнал, что AI-логика подбора форматов слабая).

## 📊 БЛОК 2: КОНТЕНТ ДЛЯ ГУГЛ-ФОРМЫ

*Скопируйте эти вопросы в Google Forms для сбора количественных данных.*

### Секция 1: Первое впечатление (Шкала 1-5)
1. **Визуальный комфорт:** Насколько цветовая гамма и шрифты соответствуют вашему образу эксперта? (1 — "Слишком просто/AI-шно", 5 — "Идеальное попадание в мой бренд").
2. **Понятность процесса:** Было ли ясно, что делает система, пока вы ждали результат?

### Секция 2: Ценность форматов (Множественный выбор)
Какие типы карточек оказались для вас наиболее полезными?
- [ ] Чек-листы
- [ ] Памятки (советы при мелтдауне)
- [ ] Алгоритмы (визуальное расписание)
- [ ] Карточки-цитаты эксперта
- [ ] Интерактивные вопросы для аудитории

### Секция 3: Замена инструментов
1. **Сравнение с Canva:** Если бы этот сервис стоил $15/мес, заменил бы он вам ручную работу в Canva для создания Pinterest-контента? (Да / Нет / Частично).
2. **Готовность к публикации:** Какой % карточек из пака вы готовы выложить в Pinterest "как есть", без правок? (0-100%).

### Секция 4: Открытый вопрос
Что самое раздражающее в процессе создания контента осталось нерешенным в этом прототипе?
