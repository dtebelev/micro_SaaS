# ГОЛОС И ФОКУС: Наташа (Архитектор надежды)

## 1. ФОКУС
**Целевой пользователь:** Наташа (32 года), проект «Naturonata». Эксперт по аутизму с 9-летним опытом, «мама-оркестр» в режиме крайнего дефицита ресурса.
**Критический путь (Happy Path):** 
1. Наташа вставляет URL своей новой экспертной статьи.
2. Система извлекает 10 смысловых карточек (чек-листы, советы для мам, алгоритмы действий).
3. Наташа за 2 минуты правит заголовки на экране проверки.
4. Скачивает готовый пак «образовательных пинов», который выглядит экспертно и сенсорно-дружелюбно (не «AI-мусор»).

## 2. ГОЛОС (Tone of Voice)
На языке Наташи: она устала от «пустых нейросетей» и «дней сурка», ей нужна глубокая экспертиза, упакованная быстро, но бережно.

### Правила тона:
1. **Бережное отношение ко времени.** Избегаем лишних слов. Пишем коротко, по делу, чтобы она могла прочитать экран, пока ребенок спит.
2. **Экспертная глубина без пафоса.** Используем термины из ниши аутизма (сенсорная интеграция, чек-листы, алгоритмы), но простым человеческим языком «от мамы к маме».
3. **Анти-нейросетевой фильтр.** Избегаем восторженного «AI-маркетинга». Текст должен звучать так, будто его написал методист-эксперт, а не робот.

### Словарик «Говорим / Не говорим»
| Говорим | Не говорим |
| :--- | :--- |
| «Преврати статью в смыслы» | «Сгенерируй крутой контент через AI» |
| «Пакет карточек для мам» | «Коллекция модных креативов» |
| «Готово к загрузке» | «Ультра-быстрая генерация графики» |
| «Сенсорно-чистый дизайн» | «Трендовый яркий визуал» |

## 3. ФОРМ-ФАКТОР
**Цель:** Desktop (Web App / PWA).
**Обоснование:** Согласно блоку 1.5 Чертежа, Наташа работает со сложным экспертным контентом за ноутбуком. Мобильный сценарий — только для быстрого просмотра, основная работа по сборке контента — десктоп.
